# Inbox

Drop gated or licensed material here. Everything in this folder except this file
is gitignored.

Name files `<source-id>--<description>.<ext>`, using the id from
`../registry.yaml` — e.g. `weichert-supplier-api--weichert-api.odt`. If a source
has no registry entry yet, use a short descriptive id and it will be added.

The current list of requested items is every registry entry with
`status: needs-user`.
